# 👋 Mes projets — Développement web & projet scolaire

Bienvenue sur mon GitHub !

Je partage ici deux projets qui m'ont permis de découvrir de nouvelles compétences, d'apprendre à travailler sur des idées concrètes et de progresser au fil de mes expériences.

## 🚀 Mes projets

### 💻 1. Portfolio — Mes premiers pas en HTML et CSS

J'ai créé un site web de type **portfolio** pour apprendre les bases du développement web. Ce projet m'a notamment permis de pratiquer la structure d'une page en **HTML**, la mise en forme avec **CSS** et l'utilisation de **Flexbox** pour organiser les éléments.

**Compétences travaillées :** HTML, CSS, Flexbox, organisation d'une page web.

➡️ [Découvrir la page du projet Portfolio](projets/portfolio.md)

### 🚲 2. Vélomobile — Projet réalisé au lycée

Dans le cadre d'un projet au lycée, j'ai travaillé sur le thème du **vélomobile**, un véhicule à propulsion humaine, généralement doté d'une carrosserie aérodynamique. Cette expérience m'a permis d'aborder un sujet technique dans un cadre scolaire.

**Thèmes abordés :** mobilité, réflexion technique et démarche de projet.

➡️ [Découvrir la page du projet Vélomobile](projets/velomobile.md)

## 📚 Ce que ces projets m'ont apporté

- Découvrir les bases de la création d'un site web.
- Comprendre comment HTML et CSS fonctionnent ensemble.
- Apprendre à utiliser Flexbox pour construire des mises en page.
- Développer ma curiosité et mon autonomie à travers des projets concrets.
